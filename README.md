# HTML অ্যানিমেশন → MP4

অ্যানিমেটেড HTML ফাইল আপলোড করলে সার্ভার headless Chromium-এ সেটা চালিয়ে
রেকর্ড করে H.264 MP4 বানিয়ে দেয়। চাইলে অডিও (wav/mp3) জুড়ে দেওয়া যায়।

## কীভাবে কাজ করে

1. HTML ফাইল আপলোড হয় (আর ঐচ্ছিক অডিও)।
2. Playwright দিয়ে headless Chromium খোলা হয়, ৯:১৬ ভিউপোর্টে (ডিফল্ট
   ৭২০x১২৮০) পেজ লোড করা হয়।
3. পেজে `TOTAL_DURATION` থাকলে সেখান থেকে সময় নেওয়া হয়, নাহলে হাতে
   দেওয়া সময় ব্যবহার হয়। ভিউপোর্টের মাঝখানে ক্লিক করা হয় — start
   overlay থাকলে অ্যানিমেশন শুরু হয়।
4. Playwright-এর ভিডিও রেকর্ডিং পুরো ভিউপোর্ট ধরে — canvas-এর ছবি আর DOM
   ওভারলে (HUD লেখা) দুটোই ভিডিওতে আসে।
5. ffmpeg দিয়ে WebM → H.264 MP4 (yuv420p, CRF 21, faststart); অডিও
   থাকলে AAC হিসেবে মেশানো হয় (অডিও ছোট হলে নীরবতা দিয়ে প্যাড করা হয়)।

## ফাইল

- `app.py` — Streamlit UI (বাংলা)
- `render.py` — রেকর্ড + এনকোড লজিক (Playwright + ffmpeg)
- `requirements.txt` — streamlit, playwright
- `packages.txt` — ffmpeg, বাংলা ফন্ট, Chromium-এর সিস্টেম লাইব্রেরি

## প্রথমবার চালু

প্রথমবার চালু হতে `playwright install chromium` দিয়ে ব্রাউজার ডাউনলোড
হয় (~১৬০ MB) — অ্যাপ নিজে সেটা করে নেয়, তবে কয়েক মিনিট লাগতে পারে।
এরপর প্রতিবার শুধু রেন্ডারের সময় লাগে।

## সীমাবদ্ধতা

- **রিয়েল-টাইম রেন্ডার:** ৫৫ সেকেন্ডের অ্যানিমেশন বানাতে রেকর্ড ৫৫
  সেকেন্ড + এনকোড আরও ~৩০–৬০ সেকেন্ড লাগে। এটা fast-forward করা যায়
  না — পেজের অ্যানিমেশন আসল ঘড়ি (`performance.now()`) ধরে চলে।
- **RAM:** headless Chromium + Streamlit মিলিয়ে ~৫০০ MB–১ GB লাগতে
  পারে — Streamlit Cloud ফ্রি টিয়ারে চলে, তবে একসাথে একটাই রেন্ডার
  করা নিরাপদ।
- **ফ্রেমরেট:** Playwright-এর রেকর্ডিং ২৫ fps।
- **অডিও:** পেজের নিজের শব্দ (Web Audio) রেকর্ড হয় না — শুধু আপলোড
  করা অডিও ফাইল MP4-এ জোড়া দেওয়া যায়।
- **বাংলা ফন্ট:** সার্ভারে বাংলা ফন্ট না থাকলে HUD লেখা বাক্স দেখাতে
  পারে — `packages.txt`-এ `fonts-beng` রাখা আছে সেজন্য।
